# Typing Speed Tester

A simple browser-based typing speed test built with vanilla HTML, CSS, and JavaScript.

## Features
- Choose a time limit: 15s, 30s, 60s, or 120s
- Live WPM (words per minute), accuracy, and error tracking
- Character-by-character highlighting (correct/incorrect/current)
- Endless word stream so you never run out of text before time's up
- Restart or try again at any point

## Usage
Open `index.html` in a browser and start typing and enhance your speed.
